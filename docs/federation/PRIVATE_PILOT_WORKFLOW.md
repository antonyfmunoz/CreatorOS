# CreativesOS private-pilot workflow: audience to commerce

## Objective

Use CreativesOS to operate a real creator/business loop for Empyrean Studios:
plan content, publish with local approval, grow audience/community, distribute,
sell an offer, and inspect attributable results.

## Required proof trail

```text
intent → campaign or draft → local authority check → approved local action
→ durable event/outcome → reconciliation when UMH is available → metric/result
```

## Pilot path

1. Ensure the operator has a default business and a clearly named offer.
2. Create a content draft and attach public or entitled private assets.
3. Create a campaign with objective, targeting rationale, and success metric.
4. Publish only after local approval when the operation is externally visible.
5. Distribute through connected adapters only after the provider path has proof
   of authentication and destination scope.
6. Open a community only when membership and moderation policy are ready.
7. Prefer native LiveKit community rooms. Record only after every current
   participant grants recording consent and at least one participant
   intentionally publishes a microphone, camera, or shared screen. Use the
   private recording lineage and terminal provider status as the proof trail.
   Do not start transcription or realtime AI until the disclosed external agent
   runtime is configured and every current participant grants that capability.
8. Complete a sandbox purchase and verify order, entitlement, and creator
   earnings allocation without exposing provider credentials.
9. Capture campaign and commerce results, then evaluate whether the workflow
   reduced context switching and increased a real operating metric.

## Success criteria

- The local workflow completes if UMH is offline.
- Every external action has an identifiable local actor, business tenant, and
  result.
- No private content, payment data, or room data crosses product boundaries
  without the documented policy and consent basis.
- A qualified UMH run can later reconcile the same local events without
  changing or rewriting local history.
